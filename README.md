# c learning_2

#### 介绍
这是我第二个存放C语言代码的仓库。第一个为c learning

#### 软件架构
本仓库包含了一系列C语言代码和C++代码，主要为我日常练习和项目开发中的积累。
代码涵盖了数据结构、算法等多个领域，旨在帮助我巩固和提升编程技能。


#### 安装教程
1. 克隆仓库到本地：
   ```bash
   git clone https://gitee.com/wxk38bdc/c-learning_2.git

   ```
2. 进入仓库目录：
   ```bash
   cd c-learning_2
   ```
3.  编译代码：
   ```bash
   gcc -o output_file input_file.c
   ```
   或者
   ```bash
   g++ -o output_file input_file.cpp
   ```
4. 运行程序：
   ```bash
   ./output_file
   ```
